设计工具插件性能排查与修复

独立排查 · 源码级定位 · 沉淀为可复用脚本与文档

  • 背景日常使用的 Figma 汉化增强版在框选、拖动时严重掉帧，直接影响设计效率。
  • 行动先做进程级 CPU 采样区分 renderer / GPU 瓶颈，再阅读注入模块源码，定位到两组 MutationObserver 问题：全量 TreeWalker 扫描 body、零节流的页面监听配合 debounce 导致每约 200ms 全树 querySelector 并触发强制重排。随后编写幂等补丁脚本，支持一键切换原生模式做二分验证与回滚。
  • 结果形成可重复执行的诊断与修复工具，并输出完整的排查记录文档；同类工具的性能问题此后可快速定位。

素材批处理与图片工具链

个人工具 · Python + Pillow + ffmpeg

  • 背景站点需要批量处理大量素材：统一尺寸、转格式、压缩、清理水印，手动逐个处理耗时且易出错。
  • 行动用 Python + Pillow 编写批处理脚本，配合 ffmpeg 处理音视频素材；全部依赖安装在隔离的虚拟环境中，不污染系统环境，换机可直接复现。
  • 结果重复劳动脚本化，批量处理从“手动逐个点”变成一条命令；工具链可迁移到后续任何素材项目。
