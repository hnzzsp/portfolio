保存

保存会把 data.json 直接提交到仓库 main 分支， GitHub Pages 重新构建后前台自动生效，通常 1 分钟内，无需改代码、无需本地部署。

修改管理密码

提交后会改写 admin.html 里的 PASS_SHA256 常量并重新发布， 同样不需要你手动改代码。新密码请务必自己记住——忘了只能本地重新生成一份 admin.html。

照片 / 源文件上传

图片、PSD/AI 源文件、PDF、ZIP 都可以传，直接存进仓库 assets/ 目录并立即上线。 单文件建议 ≤ 40MB（太大会超出接口限制）；文件名会自动清理空格与特殊字符。

数据与存储说明

· 展示数据：存在仓库根目录 data.json，公开可读，前台加载它渲染页面。
· 管理密码：只存哈希，写在本页顶部 ADMIN_CONFIG.PASS_SHA256。
· GitHub 令牌：只在当前标签页内存中，关闭即失效，不落盘、不进仓库。
· 登录状态：sessionStorage，关闭标签页自动退出。
· 如果 data.json 加载失败，前台会自动回退到 index.html 里的静态内容，不会白屏。
